# 🍏 Magic Keyboard Utility for Linux

A lightweight, portable Linux utility for the Apple Magic Keyboard.

## ✨ Features
* 🔋 **Battery Indicator**: Displays battery percentage over Bluetooth.
* ⌨️ **Fn-Key Toggle**: Switch between standard F1–F12 and Apple Media controls.
* 🔄 **Modifier Swapper**: Swap Option (Alt) and Command (Super/Windows) keys.
* 🔒 **Touch ID Key Setup**: Guides remapping the Touch ID sensor into an instant screen-lock key on Linux.
